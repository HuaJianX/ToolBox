# 三、怎么打包成无广告安装包

## 1. 一句话版本

```powershell
winget install --id JRSoftware.InnoSetup      # 只需装一次
powershell -ExecutionPolicy Bypass -File installer\build-installer.ps1
```

> `-ExecutionPolicy Bypass` 不能省：Windows 客户端默认的执行策略是 Restricted，
> 不加这个参数，`.ps1` 会直接被拦下不让跑。装好 PowerShell 7 的话，`pwsh -File` 也行。

产物：`dist\电脑工具百宝箱-1.0.0-安装包.exe`

## 2. 打包脚本具体干了什么

`installer\build-installer.ps1` 四步：

| 步骤 | 做什么 | 为什么 |
|---|---|---|
| 1 | 跑 `tests\ToolBox.SmokeTest` | 自检不过就不该出包（`-SkipTests` 可跳过） |
| 2 | 检查 `tools\` 里 ffmpeg / poppler / pandoc 在不在 | 缺了会在安装包里留个哑巴功能，先提醒 |
| 3 | `dotnet publish` 到 `dist\publish` | 见下面第 4 节 |
| 4 | 给 `setup.iss` 补 UTF-8 BOM，再调 `ISCC.exe` | **不补 BOM 中文会变乱码**，见第 7 节 |

**为什么不用单文件发布（`PublishSingleFile`）？**
程序带 Magick.NET 的原生 dll 和 `tools\` 里几百 MB 的转换组件。
单文件发布需要把原生库解压到临时目录才能加载，启动会慢一拍，
而 Inno Setup 本来就会用 lzma2 整体压缩，体积上并不吃亏。
所以发布成**普通文件夹**，安装包负责压缩。

## 3. 安装包「无广告」体现在哪

这是可以逐条验证的，不是口号。`installer\setup.iss` 里**没有**这些段：

| 常见的流氓做法 | 本安装包 |
|---|---|
| 捆绑第三方软件、推荐安装别的程序 | ❌ 没有。整个 `[Files]` 段只有一行，来源就是 `dist\publish` |
| 改浏览器首页 / 默认搜索引擎 / 加浏览器插件 | ❌ 没有 `[Registry]` 段，一个注册表键都不写 |
| 抢文件关联（.jpg 双击变成你的程序打开） | ❌ 没有 `[Registry]` 的文件关联项 |
| 装后台常驻服务 / 计划任务 / 开机自启 | ❌ 没有 `[Run]` 的常驻项，只有「装完是否马上打开」 |
| 安装时偷偷联网下载东西 | ❌ 编译期就把所有文件打进去了，安装过程零网络请求 |
| 卸载卸不干净、留一堆残留 | ❌ 标准卸载，安装进去的文件全部清理 |
| 必须管理员权限、必须登录账号 | ❌ `PrivilegesRequired=lowest`，装进用户目录即可 |

程序运行时同样干净：**没有联网代码**（整个工程搜不到 `HttpClient` / `WebClient`），
没有登录，没有会员，没有激活，没有遥测。

### 怎么自己验证

```powershell
# 1. 看安装包里到底有什么
& "$env:ProgramFiles(x86)\Inno Setup 6\ISCC.exe" /?     # 确认是官方 ISCC

# 2. 装一遍，然后看装了什么
Get-ChildItem "$env:LOCALAPPDATA\Programs\电脑工具百宝箱" -Recurse | Measure-Object

# 3. 确认没写注册表（除了标准的卸载信息）
reg query "HKCU\Software\电脑工具百宝箱"        # 应该报「找不到」

# 4. 确认程序运行时不联网：断网，所有功能照样用
```

> ⚠️ 一定从 **jrsoftware.org 官网** 或 winget 装 Inno Setup。
> 网上有第三方改过的「Inno Setup 增强版」会往安装包里塞广告，官方版没有。

## 4. 体积：两档可选

```powershell
# A. 默认：自包含，用户不用装任何运行时（最省事，推荐）
powershell -ExecutionPolicy Bypass -File installer\build-installer.ps1

# B. 瘦身：依赖 .NET 10 桌面运行时，发布目录小 6 倍
powershell -ExecutionPolicy Bypass -File installer\build-installer.ps1 -FrameworkDependent
```

| 档位 | 发布目录（实测） | 安装包（估计） | 用户需要先装什么 |
|---|---|---|---|
| A 自包含 | **158 MB** / 258 个文件 | 约 60 MB | 什么都不用 |
| B 依赖运行时 | **26.5 MB** / 7 个文件 | 约 12–18 MB | .NET 10 桌面运行时（约 55 MB） |

> 上表是本机实测结果（.NET 10.0.303，**含 Magick.NET，不含 tools**）。
> 自包含目录用 deflate 压一遍是 68.1 MB；Inno Setup 用的 lzma2 比 deflate 更强，
> 所以 A 档安装包落在 60 MB 上下。**注意这些数字都不含 tools 里的 ffmpeg**，见下。

B 档要静默装运行时的话，发布前执行：

```powershell
winget install --id Microsoft.DotNet.DesktopRuntime.10 --silent
# 或者把桌面运行时的安装包跟你的安装包放一起，引导用户先装
```

### 体积大头在哪（实测）

| 组成 | 大小 | 能不能省 |
|---|---|---|
| `Magick.Native-Q16-x64.dll` | **23.1 MB** | ❌ 图片功能的全部家当，省了就没有图片转换 |
| `PresentationFramework` + `PresentationCore` | 22.9 MB | ✅ 改 B 档（用系统装的运行时）就没了 |
| `coreclr` + `System.Private.CoreLib` + 其它运行时 | 约 60 MB | ✅ 同上 |
| `D3DCompiler_47_cor3.dll` 等 WPF 图形栈 | 约 20 MB | ✅ 同上 |
| `tools\ffmpeg\bin`（ffmpeg.exe + ffprobe.exe） | 下载包 **106 MB**，解压后约 150–170 MB | ⚠️ 见下 |
| `tools\poppler` | 约 20 MB | ⚠️ PDF 转图片/文字要用 |
| `tools\pandoc` | 约 30 MB | ✅ 可省，只是 Markdown 不排版 |

### ffmpeg 是最大的体积黑洞，这里要说清楚

FFmpeg 的 Windows 构建是**静态链接**的：`ffmpeg.exe` 和 `ffprobe.exe` 各自
把全世界的编解码器都编进了同一个可执行文件，所以每个都有 80 MB 上下。
`get-tools.ps1` 跑完会打印真实大小，到时候看一眼就知道。

于是「离线可用」和「体积小」在音视频这一块是直接冲突的。三个选择：

| 方案 | 安装包 | 音视频开箱可用？ |
|---|---|---|
| ① 全带（自包含 + ffmpeg + poppler + pandoc） | 约 160–200 MB | ✅ 装完什么都能转 |
| ② 全带（依赖运行时 + 全部组件） | 约 70–90 MB | ✅ 但用户得先有 .NET 10 桌面运行时 |
| ③ 不带 ffmpeg（安装包约 60 MB / 18 MB） | 小 | ❌ 需用户跑一次 `get-tools.ps1` |

**建议**：既然需求里写明「音视频转换」是 MVP 功能、而且强调「断网可用」，
那就选 ① 或 ②，把 ffmpeg 带上 —— 让用户装完就能用，比省 100 MB 重要。
真要压体积，用 ②，然后在 Inno 里把 .NET 桌面运行时作为前置条件一并安装。

> **一个小优化**：`ffprobe.exe` 只有一个用途 —— 问出音视频总时长来算百分比进度。
> 不带它的话能省约 85 MB，代价是进度条从「百分比」变成「来回滚动」。
> 代码里已经处理了这种情况（`FfmpegConverter.ProbeDurationAsync` 问不到就返回 0，
> 界面自动切成不确定进度），所以删掉 `tools\ffmpeg\bin\ffprobe.exe` 完全不会报错。
> 但为了体验，建议留着。

## 5. 装完之后是什么样

```
%LOCALAPPDATA%\Programs\电脑工具百宝箱\      ← 不需要管理员权限
├── 电脑工具百宝箱.exe                      ← 桌面和开始菜单的快捷方式指这里
├── app.ico
├── 电脑工具百宝箱.dll
├── Magick.NET-Q16-x64.dll
├── runtimes\win-x64\native\...             ← ImageMagick 原生库
└── tools\                                  ← 免安装组件，跟着 exe 走
    ├── ffmpeg\bin\ffmpeg.exe
    ├── ffmpeg\bin\ffprobe.exe
    ├── poppler\Library\bin\pdftoppm.exe
    └── pandoc\pandoc.exe
```

`tools\` 在程序目录里有个好处：**整个文件夹拷到 U 盘或另一台电脑，照样能用**，
真正的绿色版。`ToolLocator.cs` 的搜索顺序第一项就是 `程序目录\tools`。

用户的产出和日志**不在**安装目录里，所以升级、重装、卸载都不会丢：

- 转好的文件：`%USERPROFILE%\转换结果\`
- 日志：`%LOCALAPPDATA%\电脑工具百宝箱\运行日志.txt`

## 6. 代码签名：去掉「未知发布者」警告

不签名的话，用户第一次运行会看到 Windows SmartScreen 的蓝色警告框
（「Windows 已保护你的电脑」）。这不是病毒，是没签名的正常表现，
但给老人用会吓到人。要彻底解决就得买代码签名证书：

```powershell
# 用 Inno Setup 自带的签名工具（在 setup.iss 的 [Setup] 段加）
# SignTool=signtool sign /fd sha256 /tr http://timestamp.digicert.com /td sha256 /f "证书.pfx" /p "密码" $f
```

- **OV 证书**（约 ¥1000+/年）：签完还是要攒几天信誉，SmartScreen 警告才会消失。
- **EV 证书**（约 ¥3000+/年，需要硬件 UKey）：签完立刻就没有警告。

没预算的话，退而求其次：在官网/群里说明「本程序没有数字签名，
安装时如果出现蓝色提示，点『更多信息』→『仍要运行』」，
再把安装包的 **SHA-256 校验值**公布出去，让大家自己核对文件没被篡改过：

```powershell
Get-FileHash 'dist\电脑工具百宝箱-1.0.0-安装包.exe' -Algorithm SHA256
```

## 7. 两个编码大坑（都踩过，已修）

打包脚本里有两处**必须**用「带 BOM 的 UTF-8」，否则中文全乱：

| 文件 | 不补 BOM 会怎样 |
|---|---|
| `installer\setup.iss` | Inno Setup 按 ANSI 读，安装界面上的中文变成一串问号和乱码 |
| `tools\get-tools.ps1` | PowerShell 按系统 ANSI 代码页读，中文乱码**直接导致语法错误、脚本跑不起来** |

`build-installer.ps1` 里的 `Ensure-Utf8Bom` 会自动处理 `setup.iss`。
如果你手工编辑过这些文件，重新跑一次打包脚本即可。想手动修：

```powershell
$p = 'D:\X\installer\setup.iss'
$text = [System.IO.File]::ReadAllText($p, [System.Text.UTF8Encoding]::new($false))
[System.IO.File]::WriteAllText($p, $text, [System.Text.UTF8Encoding]::new($true))
```

`tools\make-icon.ps1` 则是故意写成**纯 ASCII**（注释也都是英文），
从根上避开这个坑。

## 8. 想要中文安装界面

Inno Setup 6 自带不带简体中文语言文件。想要中文向导：

1. 去 Inno Setup 官网的 Translations 页面下载 `ChineseSimplified.isl`
2. 放到 Inno Setup 安装目录的 `Languages\` 文件夹下
3. 打开 `installer\setup.iss`，把这一行前面的分号去掉：

```ini
;Name: "chinesesimplified"; MessagesFile: "compiler:Languages\ChineseSimplified.isl"
```

不弄也没关系：安装包文件名是中文的，需要点的地方只有「下一步」和「安装」两个按钮。

## 9. 手工打包（不用脚本）

```powershell
# 1. 发布
dotnet publish src\ToolBox.App\ToolBox.App.csproj `
    -c Release -r win-x64 -o dist\publish `
    -p:SelfContained=true -p:DebugType=none

# 2. 编译安装包（用 Inno Setup 编译器，或图形界面按 F9）
& "$env:ProgramFiles(x86)\Inno Setup 6\ISCC.exe" installer\setup.iss
```

## 10. 顺带一提：安装包里那个 LibreOffice 提示

`setup.iss` 里有一小段 `[Code]`：装完最后一页会检查
`C:\Program Files\LibreOffice\program\soffice.exe` 在不在。
不在就补一句说明：

> 提示：没有检测到 LibreOffice，所以「文档转换」和「PDF 转 Word」暂时用不了。
> 想用的话，自己装一个 LibreOffice 就行，程序会自动找到它。
> 其它功能（图片、音频、视频、PDF 转图片/文字）不受影响，现在就能用。

这比「装完发现某个功能灰着不知道为什么」要好。而且它是**提示**，
不会拦着用户、不会强行下载 350 MB 的东西。
